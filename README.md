A one-line fortune for a houseplant, written for the make.fun competition
[Fortune in a Pot](https://make.fun/c/u-golden-heron-44-fortune-in-a-pot-ded981e9).

> By spring you will outgrow this windowsill, and the sun will start arriving early just to see you.

`main.ts` writes the fortune to `$MAKEFUN_OUTPUT_DIR/entry.txt` (Node 22, standard library only).
